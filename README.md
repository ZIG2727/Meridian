# Meridian

Meridian — учебная среда с тремя самостоятельными курсами: английский (RU → EN), шахматы на русском языке и Python. Проект использует vanilla JavaScript ES-модули, CSS и JSON; серверная часть, Node.js и production-сборка для работы сайта не нужны.

## Курсы

- **Английский:** 15 тематических юнитов уровня A1–B1, 60 коротких уроков и 600 карточек с естественными примерами. Повторение карточек рассчитывается по SM-2.
- **Шахматы:** 15 юнитов и 60 уроков по основам, тактике, окончаниям и дебютам. Каждый урок содержит FEN-позицию и мини-тест.
- **Python:** 15 юнитов и 60 практических уроков: основы, управление потоком, структуры данных, функции, текстовые данные и ошибки. Редактор использует ограниченный учебный интерпретатор, а не запускает произвольный Python.

## Навигация

- `#/english`, `#/chess`, `#/python` — экран курса с группами юнитов.
- `#/<module>/<unitId>` — список уроков выбранного юнита.
- `#/<module>/<unitId>/<lessonId>` — отдельный урок.

На экране курса есть поиск по названиям уроков и тегам. Юнит загружается только после открытия; манифест курса загружается отдельно. Прогресс связан со стабильными ID, а не с порядком элементов в JSON.

## Структура данных

```text
data/
├── english/
│   ├── curriculum.json
│   └── units/<unitId>.json
├── chess/
│   ├── curriculum.json
│   └── units/<unitId>.json
└── python/
    ├── curriculum.json
    └── units/<unitId>.json
```

В каждом манифесте — 15 юнитов по 4 урока. В содержимом юнита — ровно 4 полноценных урока. Идентификаторы юнитов, уроков и английских карточек стабильны.

## Сохранение и безопасность

Данные занятий хранятся в localStorage с префиксом `mrd:`. Английский использует `mrd:v3:english:srs`, завершённые уроки — `mrd:v3:<module>:completed`, текущая сессия — `mrd:v3:<module>:session`, последний открытый урок — `mrd:v3:lastLesson`. Профиль, имя, дневная цель, XP и недельная активность хранятся локально в `mrd:v3:profile`; данные не отправляются на сервер. Существующий прогресс автоматически учитывается при первом открытии профиля.

Python runner поддерживает учебные выражения и конструкции: строки и числа, bool, фиксированный пример ввода, списки, кортежи, словари, множества, индексацию и срезы, базовые методы коллекций, if/elif/else, ограниченные циклы, break/continue, безопасный try/except для ValueError и простые функции. Запрещены импорты, произвольное исполнение, доступ к диску, сеть и системные команды. Файловые упражнения используют виртуальные строковые данные.

Шахматная доска показывает позиции из FEN и даёт геометрические подсказки при выборе фигуры. Это не полноценный шахматный движок и не проверяет безопасность короля или все специальные ходы.

## Локальный запуск

Откройте каталог проекта через локальный HTTP-сервер, например Live Server. Не запускайте `index.html` через `file://`: браузер может заблокировать загрузку JSON и ES-модулей.

## Проверка

Сценарий `scripts/validate-v3.mjs` проверяет структуру курсов, ID, карточки, FEN, тесты, безопасный Python runner, профиль и расчёт аналитики. Playwright smoke test открывает главную и три предмета на ширинах 360, 768 и 1280 px, проверяет отсутствие горизонтальной прокрутки, работу раскрытия юнитов, загрузку изображений или fallback, сохранение настроек профиля и начисление XP без повторов. Скриншоты сохраняются в GitHub Actions artifact. Проверка запускается для pull request в `main` и push в основные рабочие ветки.

## Deploy to GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/ (root)**, затем сохраните.
4. После публикации откройте https://zig2727.github.io/Meridian/.

Проект статический и не требует Node.js или шага сборки для публикации. Изменения V3 находятся в ветке `v3-curriculum`; они попадут на основной сайт после принятия этой ветки в `main`.

## Профиль и аналитика V3.2

На главной странице есть локальный профиль: отображаемое имя, дневная цель (1–10 уроков), опыт (20 XP за первое завершение урока), число завершённых уроков, текущая серия дней и график активности за последние семь дней. Повторное завершение одного и того же ID не начисляет XP повторно. Исторические завершённые уроки мигрируют в счётчик опыта без выдумывания дат активности. Если localStorage недоступен, учебные разделы остаются доступными.


## Английский V3.3 — активный перевод

Вместо простого раскрытия карточки ученик сначала вводит перевод на английском и нажимает «Проверить» (Enter тоже работает). Ответ проверяется без учёта регистра, лишних пробелов и конечной пунктуации. После проверки показываются правильная фраза и пример, затем ученик оценивает сложность воспоминания для SM-2. Можно открыть ответ, если перевод пока неизвестен.
