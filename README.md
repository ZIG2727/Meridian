# Meridian

Meridian — спокойная учебная среда с тремя маршрутами: английский (RU → EN), шахматы на русском языке и основы Python. Проект собран на vanilla JavaScript с ES-модулями, CSS и JSON. Состояние занятий хранится локально в браузере; серверная часть и сборка не требуются.

## Разделы

- **Английский:** карточки слов и фраз с интервальным повторением по SM-2.
- **Шахматы:** короткие уроки, вопросы с вариантами и визуальные примеры ходов.
- **Python:** теория и редактор, который сверяет решение с эталонным кодом. Введённый код не исполняется.

## Запуск локально

Откройте каталог проекта через любой локальный HTTP-сервер, например Live Server в редакторе. Затем перейдите по адресу, который покажет сервер. Не открывайте index.html напрямую через file://: браузер может блокировать загрузку JSON и ES-модулей.

## Deploy to GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/ (root)**, затем сохраните.
4. После публикации откройте https://<username>.github.io/<repo>/.

Для Meridian в этом репозитории адрес проекта будет https://zig2727.github.io/Meridian/. Публикация не требует Node.js или шага сборки.

## Сохранение данных

Прогресс и незавершённые сессии записываются в localStorage с префиксом mrd:. Данные остаются в текущем браузере и не синхронизируются между устройствами. Очистка данных сайта удалит локальный прогресс.

## Проверка Python-уроков

Редактор сравнивает введённый текст с эталонным решением из JSON. Это намеренно не Python-интерпретатор: код не запускается, а проверка не может выполнять произвольные команды. Поле expectedOutput в наборах уроков содержит эталонный текст решения для такого сравнения.

## Шахматная доска

lib/chessboard.min.js — небольшой локальный компонент отображения позиции для Meridian с методом movePiece. Он отвечает только за доску и визуальное перемещение фигуры, а не за проверку легальности ходов. Правила объясняются в учебных текстах; доска не является шахматным движком.
